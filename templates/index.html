Cloud computing, made simple

What is the cloud?

Cloud storage means saving files on computers called servers that you can access over the internet, instead of keeping every copy only on your own device.

For example, when a service stores your photos online, you may be able to open them from another device after signing in. Actual access depends on that service's storage, account and security setup.

Public cloud Services shared across customers, with separate accounts.
Private cloud Cloud infrastructure dedicated to one organization.
Hybrid cloud A combination of private and public cloud resources.

Sandhu Drive is being built with a privacy-aware approach. The current version includes basic file-handling safeguards, but it is not yet a complete multi-user encrypted cloud platform.

Got questions?

Frequently asked questions.

Quick answers about the current Sandhu Drive project.

What is Sandhu Drive?

Sandhu Drive is a file-management web project designed around a modern cloud-drive style interface.

Is the 500 MB limit available?

The application is configured for files up to 500 MB, but the total request limit, hosting provider and server configuration can also affect uploads.

Are the paid plans working?

No. Plus and Pro are proposed pricing examples. Real subscriptions require a payment provider and backend entitlement checks.

Are my files permanently stored?

Not necessarily. The current version uses server-side file storage. Temporary hosting storage may be lost when the service restarts or redeploys unless persistent storage is configured.

Does Sandhu Drive have end-to-end encryption?

Not in the current implementation. Do not upload sensitive files expecting end-to-end encrypted storage.

Will it work on mobile and tablets?

The interface uses responsive layouts for phones, tablets and desktops. Upload size and browser capabilities can vary by device.
